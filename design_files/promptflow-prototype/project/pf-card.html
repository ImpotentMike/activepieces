Purpose

One shell, four compositions

Every collection-item card in PromptFlow uses the same outer shell — same radius, padding, border, shadow, hover treatment. Variants change what is laid out inside, never the shape of the container itself.

Click target is always the entire card. Internal controls (overflow menu, status pill) don't compete with the primary click.

Variants → PRD principle

One-line rationale

  • Stat tileConfidence through clarity One metric per card, big number, trend in a single chip — readable in under a second.
  • Template cardProgressive disclosure Description and CTA are hidden in plain sight until intent (hover/focus) — the grid stays scannable.
  • Project cardGuided, not technical Three plain-language stats (workflows, members, last run) — no project IDs surfaced.
  • Workflow cardVisual transparency Status pill always top-right, trigger type icon-led — you see what the system is doing.
  • Disabled stateTrust and safety Archived workflows are visibly inert (60% opacity, gray fill, no hover lift) — they exist for the record but you can't accidentally trigger them.
Accessibility

Keyboard, ARIA, focus

  • click targetWhole card is a <button> or <a>. Single tab stop per card.
  • overflow menuThe "…" affordance is decorative on the card surface; the real menu lives on the page row menu, opened via right-click or keyboard Menu key. Avoids nested buttons.
  • focus ring3px var(--fr-primary) + primary border on focus-visible. Visible only on keyboard focus, never suppressed.
  • hover ≠ focusHover reveals CTA on Template card; focus reveals the same CTA via :focus-within so keyboard users see it too.
  • disabledaria-disabled="true", not disabled — keyboard users can still focus and read the card; only activation is blocked.
  • truncationLong titles wrap to 2 lines then ellipsis via -webkit-line-clamp. Full title available via tooltip on focus (left to consumer).
  • contrastAll text/bg pairs meet WCAG AA. Disabled state at 60% opacity remains ≥4.5:1 against the gray-50 fill.
Density & layout

Where each variant lives

  • Stat tileDashboard. 4-col at ≥1280px viewport. Min card width 220px. Padding 16px (compact).
  • Template cardTemplate Library. 3-col. Min card width 280px. Padding 20px.
  • Project cardProjects list. 3-col. Min card width 280px. Padding 20px.
  • Workflow cardWorkflows tab. 3-col. Min card width 300px. Padding 20px.
  • gapAlways 16px between cards. Wraps to 2-col below 880px.

Shared shell tokensAll variants inherit these. Override only the internal composition, never the chrome.
